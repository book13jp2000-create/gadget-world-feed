# PCパーツの過去の値段（本人が用意するデータ）

ここに置いた CSV（`*.csv`、いくつでも）の値段と、Yahoo!ショッピングの毎日の記録（data ブランチの `parts-archive.json`）をつないで、ワールドの PCパーツの板のグラフ（1年・5年・全期間）にする（`parts-history.js`）。CSV を足して push すると `parts.yml` が動いて作り直す。

## 書き方（`ひな形.csv` を写して使う）

```
id,品目,日付,価格（円・税込）,メモ（出典など・任意）
rtx5080,RTX 5080,2025-02-01,198000,
rtx5080,RTX 5080,2025-03-01,189800,
ddr5,DDR5 メモリ 32GB（16GB×2）,2024-11-01,15800,
```

- 1行に「1品目・1日」の値段。日付は `2025-02-01` か `2025/2/1`。価格は数字だけ（`198,000` や `198000円` も読める）
- `id` は板の品目の id（`ひな形.csv` に全26品目の id と名前がある）。品目の名前の列は読まない（見やすさのため）
- 1日ごとでなくてよい（月に1つでも）。グラフは 1年＝週ごと、5年・全期間＝月ごとに、その区切りの最後の値を使う
- 同じ品目・同じ日に Yahoo! の記録もあれば Yahoo! を使う
- 価格の空いた行・`#` で始まる行は読まない
- このリポジトリと Pages は公開なので、置いたデータは誰でも見られる
